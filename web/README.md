# TenderScope Next.js

Νέα διεπαφή του TenderScope, παράλληλα με την υπάρχουσα εφαρμογή Streamlit.

## Τοπική εκτέλεση

```bash
pnpm install
pnpm dev
```

Άνοιξε το `http://localhost:3000`.

Η πρώτη έκδοση χρησιμοποιεί ενδεικτικές εγγραφές ώστε να εγκριθεί το design. Η Supabase θα συνδεθεί στο επόμενο στάδιο, με publishable key και RLS. Ποτέ δεν τοποθετούμε service-role/secret key σε `NEXT_PUBLIC_` μεταβλητή.
